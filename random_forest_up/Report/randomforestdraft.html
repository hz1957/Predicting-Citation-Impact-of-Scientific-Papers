4. Supervised Learning: Random Forest Performance & Hyperparameter Tuning

Evaluation & Experimental Setup

  • Task 1 (Regression): Continuous prediction of $\log(1 + \text{3-year citations})$
  • Task 2 (Classification): Top-decile citation impact identification ($\geq 41$ citations)
  • Temporal Data Split: Train split ($N=24,691$) / Held-out test split ($N=25,308$)
  • Feature Sets Evaluated: Base (Metadata + LSA Text) versus Base + Unsupervised Text Clusters ($k=8$)

4.1 Continuous Regression Performance

Random Forest regression was evaluated to examine the effect of model complexity control through hyperparameter tuning and the additional predictive value of unsupervised text cluster features. The baseline model uses an unconstrained tree depth configuration, while the tuned model applies regularization through maximum depth and minimum leaf size constraints.

Regression Key Takeaways

  • Variance Control: The untuned model exhibits severe overfitting ($\text{Train }R^2=0.844$ versus $\text{Test }R^2=0.144$). Hyperparameter tuning ($\text{depth}=20,\text{leaf}=10$) successfully reduces model complexity, decreasing training performance to $R^2=0.500$ while preserving comparable test performance.
  • Ranking Performance: The tuned base model achieves the highest Spearman correlation ($\rho=0.4605$), indicating slightly improved rank-order consistency for citation prediction under temporal generalization.
  • Cluster Augmentation Impact: Adding unsupervised text clusters provides only marginal improvement ($\Delta\text{Test }R^2\approx+0.004$), suggesting that the original LSA representation already captures most of the available text-based citation information.

Binary classification evaluates the identification of rare, highly cited papers ($\geq 41$ citations), corresponding to approximately $5.9\%$ of the held-out test population. The baseline classifier uses the default Random Forest configuration, while the tuned model applies class_weight="balanced" to increase the contribution of minority class samples during training.

Classification Key Takeaways

  • Minority-Class Recovery: The unconstrained classifier is overly conservative under severe class imbalance, identifying only $5.29\%$ of positive cases despite high precision ($47.0\%$). Applying class_weight="balanced" increases the influence of minority samples during tree construction, improving recall to $38.76\%$ and increasing the F1-score from $0.0951$ to $0.3061$.
  • Ranking Capability: Discrimination metrics remain consistent across configurations ($\text{ROC-AUC}\approx0.809$ and $\text{PR-AUC}\approx0.234$), indicating that class weighting primarily improves the classification operating point rather than substantially changing the underlying ranking ability.
  • Cluster Feature Effect: Adding unsupervised text clusters produces only minor changes in minority-class retrieval. Although recall increases slightly for the augmented tuned model ($41.03\%$), PR-AUC and ROC-AUC remain nearly unchanged, suggesting limited additional information beyond the original feature representation.

4.3 Synthesis & Conclusion

Random Forest experiments demonstrate that model regularization and class balancing affect regression and classification performance differently. For continuous citation prediction, limiting tree complexity reduces excessive training fit but does not substantially improve temporal test performance ($R^2\approx0.143-0.148$). This suggests that the dominant challenge is not model complexity alone, but distribution shift between historical training papers and future citation patterns.

For the top-decile classification task, balanced training provides a substantial practical improvement by recovering rare high-impact papers that are otherwise suppressed by class imbalance. The tuned classifier increases recall from $5.3\%$ to $38.8\%$ and improves F1-score from $0.0951$ to $0.3061$, making it a stronger operational baseline for identifying influential publications.

However, Random Forest hyperparameter exploration represents only one ensemble learning approach. Since extensive tuning of high-capacity tree ensembles can be computationally expensive and may not fully address temporal generalization, future experiments will investigate gradient boosting methods such as XGBoost. Unlike bagging-based Random Forests, boosting sequentially corrects previous prediction errors and provides additional regularization controls including tree depth constraints, learning rate, subsampling, and L1/L2 penalties.

These experiments will evaluate whether boosting-based models provide a more favorable bias–variance tradeoff and improved generalization for citation impact prediction under the same leakage-safe temporal evaluation framework.
