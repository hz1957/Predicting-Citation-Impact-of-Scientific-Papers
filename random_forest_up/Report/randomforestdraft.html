4. Supervised Learning: Random Forest Baselines & Hyperparameter Tuning

To establish a leakage-safe supervised prediction pipeline, we evaluated Random Forest models across two tasks: continuous 3-year citation count regression ($\log(1 + \text{citations})$) and top-decile binary classification ($\ge 41$ citations). All preprocessing transformers were fitted strictly on the c1 train split ($N = 24,691$) and evaluated on the held-out temporal test split ($N = 25,308$).

We evaluated two primary modeling regimes: an unconstrained baseline (default tree depth, unweighted) and a tuned/regularized regime (constrained depth, leaf size controls, and class_weight="balanced"). We then conducted a controlled feature ablation to isolate the marginal value of unsupervised text-cluster representations ($k=8$ K-Means cluster indicators and centroid distances).

4.1 Regression & Ranking Performance

Unconstrained Random Forests suffered from severe variance, memorizing the training set ($R^2 \approx 0.84$) while generalizing poorly to the temporal test set ($R^2 = 0.1412$). Restricting tree depth and leaf size controlled overfitting, shrinking the train-test generalization gap ($\Delta R^2 \approx 0.356$). Under strictly controlled hyperparameter settings, appending unsupervised cluster features (`base_plus_clusters`) yielded a +2.02% relative increase in test $R^2$ ($0.1433 \to 0.1462$) and reduced MAE, confirming that spatial cluster proximity provides unique, non-redundant structural signal.

4.2 Binary Classification Performance (Top Decile)

Top-decile papers constitute 5.9% of the temporal test set ($p \ge 41$). In the unconstrained setup without class balancing, default probability decisions ($p \ge 0.50$) created a conservative classifier that missed over 94% of true high-impact papers ($\text{Recall} = 5.29\%$).

Incorporating class_weight="balanced" dramatically shifted the decision boundary: test set recall increased nearly 8-fold from 5.29% to 38.76%, driving a 3-fold increase in test F1-score ($0.0951 \to 0.3061$). Global ranking performance remained exceptionally robust across all configurations ($\text{ROC-AUC} \approx 0.809$, $\text{PR-AUC} \approx 0.234$).

4.3 Key Synthesis

  • Hyperparameter Regularization: Constraining tree depth and leaf size successfully mitigated variance, reducing train $R^2$ from 0.84 to 0.50 and maintaining stable generalization on unseen test data.
  • Class Weighting Impact: Enforcing class_weight="balanced" resolved the conservative prediction bias, boosting minority class recall to 38.8% and tripling the test F1-score.
  • Cluster Feature Value: Holding hyperparameter configurations constant, cluster augmentation yielded a clean +2.02% relative improvement in out-of-sample $R^2$, proving that unsupervised spatial topology provides meaningful predictive value.
