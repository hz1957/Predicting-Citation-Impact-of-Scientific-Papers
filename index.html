Predicting Citation Impact of Scientific Papers

A machine learning case study using citation forecasting, clustering, and model interpretation.

Portfolio project · supervised learning · unsupervised analysis

Read Final Report View Reports

Citation counts are a widely used — if imperfect — proxy for scientific influence, and they are extremely skewed: a small fraction of papers collect most of the citations. This project builds models that forecast the citation impact of AI/ML papers at (or shortly after) publication, combining unsupervised topic exploration, supervised baselines, XGBoost feature-stack experiments, and feature-importance analysis to learn which signals actually drive predicted impact.
