3. Unsupervised Learning: Impact Archetypes

Following the proposal, we ran K-Means on the assembled feature vectors of the c1 train split (24,691 papers, 2018–2020; the temporal test split is held out). Text features are TF-IDF over title + abstract (13,775 terms) compressed to 100 dimensions with Truncated SVD and L2-normalized (LSA); the metadata block (author/reference counts, text lengths, year, frequency-encoded venue, category indicators) is standardized. We cluster twice with the same LSA text features: once with the metadata block concatenated (the proposal's assembled vectors) and once with the text features alone. Citation outcomes are used only to profile clusters, never as clustering features.

Model selection. With text + metadata features the silhouette score has a clear interior maximum at k = 3 (Fig. 2a): the three clusters match the arXiv category split almost exactly (99.9% cs.CV, 100% cs.CL, and the remaining cs.LG mass), and their outcomes already differ — 14.7% of cs.CV papers reach the corpus-wide top decile of 3-year citations versus 7.6% of the cs.LG-and-other cluster. Using the same text (LSA) features without the metadata block, the silhouette instead rises slowly and monotonically with k (Fig. 2b) — typical for text — so we fix k = 8, the largest k at which every cluster remains interpretable and well populated. This second clustering is run independently on the full corpus (not nested inside the k = 3 clusters); its clusters mostly split the three category groups further but can also cut across them (e.g. the GAN / adversarial cluster spans cs.CV and cs.LG).

Eight topical clusters with sharply different outcomes (Fig. 3). The text-only clusters are cleanly topical: 3D & object detection (C0), reinforcement learning (C1), applied ML & prediction (C2), optimization & theory (C3), deep architectures (C4), GANs & adversarial robustness (C5), image segmentation (C6), and NLP & speech (C7) — names assigned by hand from each cluster's top TF-IDF terms. UMAP and t-SNE agree on the same topical islands, an encouraging robustness check, while linear PCA shows the same coarse topic gradient with heavy overlap — the nonlinear methods are what make the structure visible. Citation outcomes separate strongly: 3D & object detection does best (median 7 citations in 3 years; 16.0% reach the corpus top decile), followed by segmentation (11.8%) and NLP (11.3%); optimization-theory papers sit lowest (median 3; 4.0%; 16% uncited). NLP is the heavy-tail cluster — mean 47.6 versus median 6 citations, reflecting a few transformer-era mega-hits — which reinforces the log-transformed target. Metadata profiles add texture: theory papers have markedly fewer authors (z = −0.40), vision papers more.

Impact concentrates in specific regions (Fig. 4). Coloring the same embeddings by log(1 + citations in 3 years) shows dense high-citation pockets in the detection/segmentation and NLP regions rather than a uniform spread — topic membership alone is informative about citation outcome.

Implications for the supervised stage. Topic membership alone is predictive of citation outcome, so (i) the SVD text features should carry substantial signal into the regressors, (ii) cluster id / distance-to-centroid are cheap engineered features worth adding, and (iii) per-cluster error analysis should be reported alongside global metrics, since a model can look accurate globally while failing on low-signal clusters such as optimization theory.
