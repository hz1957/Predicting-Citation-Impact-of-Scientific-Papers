1. Introduction & Background

The number of citations a paper accrues is a widely used—if imperfect—proxy for scientific influ- ence [1]. Citation dynamics are extremely skewed: in computer science, the most-cited 7% of papers collect over half of all citations while roughly 21% go uncited (Gini ≈ 0.73, Fig. 1) [7]—a concen- tration that has only intensified as AI publication volume has surged [2, 6]. With thousands of AI papers posted each month, this imbalance makes it hard to tell early on which work will matter; a model that forecasts impact at (or shortly after) publication could help researchers, reviewers, and libraries surface promising papers before citations accumulate, and reveal which characteristics drive attention. Text alone is a relatively weak predictor of impact—the strongest text-based models leave most of the variance unexplained [8]—while bibliometric and metadata signals available near publication consistently add substantial predictive power [1]. In this project, We study citation prediction for AI/ML papers—a fast-moving field with a large, openly catalogued literature—and use feature-importance analysis to learn which signals actually drive predicted impact, rather than assuming them in advance.

For this project milestone, we establish a complete leakage-free machine learning pipeline. After preprocessing the dataset and constructing text and metadata representations, we implement unsupervised clustering and supervised baseline models to evaluate predictive capability.

Dataset

We assemble the dataset from open sources requiring no API keys. A HuggingFace arXiv corpus provides titles, abstracts, authors, and publication dates. These records are enriched with citation counts and affiliations from OpenAlex. The dataset focuses on AI/ML categories: cs.LG, cs.CL, and cs.CV.

Approximately 50,000 papers published between 2018 and 2022 are sampled so that citation counts have sufficient time to mature. Before model development, all collected data are transformed into text and metadata feature representations to ensure an efficient and leakage-free learning pipeline.

Data sources:

  • HuggingFace ML-ArXiv Papers Dataset
  • OpenAlex Scholarly Database

2. Problem Definition

Problem. Given features describing a scientific paper at publication time (title, abstract, venue, author count, reference count, field, and year), predict its fixed-window citation count. This is formulated as a regression problem.

We also investigate a binary classification formulation: whether a paper becomes highly cited, defined as belonging to the top decile of fixed-window citations within its field and publication year.

Motivation. Reliable early estimates of scientific impact could help researchers, libraries, and reviewers prioritize rapidly growing literature. Furthermore, feature importance analysis reveals which characteristics influence eventual citation outcomes.

Citation prediction also provides an opportunity to study biases embedded in citation systems. Therefore, predictions are interpreted descriptively rather than as measures of scientific merit.

3. Methods

Dataset and Preprocessing

The dataset consists of approximately 150,000 AI and machine learning research papers collected from the arXiv categories cs.LG, cs.CL, and cs.CV. Each record contains bibliographic metadata, publication venue, author information, citation information, and extracted textual features.

The papers are divided into three temporal cohorts according to publication year. The primary experiments use the C1 cohort, where earlier papers are used for training and later papers are reserved for testing. This temporal split prevents information leakage and provides a realistic prediction setting.

Cohort Years Papers Target Purpose
C1 2018--2022 49,999 Citations within first 3 years Training / Evaluation
C2 2023--2024 50,000 Citations within first 1 year Generalization
C3 2025--2026 49,974 Citations to date Forecasting

Citation counts exhibit a strongly skewed distribution. Therefore, the prediction target is transformed using:

\[ y=\log(1+\text{target\_citations}) \]

Only information available at publication time is used for feature construction. Citation-derived variables that could introduce target leakage are excluded.

Paper titles and abstracts are converted into TF-IDF vectors and compressed into a 100-dimensional latent semantic representation using Truncated Singular Value Decomposition (LSA).

Metadata features including publication year, author count, reference count, venue frequency, document length, affiliation statistics, and arXiv category indicators are standardized using StandardScaler. All preprocessing steps are fitted only on the training split and then applied unchanged to validation and testing data.

Unsupervised Learning: K-Means Clustering

Unsupervised learning is performed on the C1 training split to discover latent topic structures and citation-impact archetypes. Two K-Means analyses are conducted:

  • Combined text and metadata representation.
  • LSA text-only representation.

The optimal number of clusters is determined using the Silhouette coefficient and Davies--Bouldin index. PCA, UMAP, and t-SNE are used for visualization of the learned feature space and citation-impact distribution.

Reason for K-Means Clustering

K-Means was selected as the primary unsupervised learning method because it scales efficiently to large high-dimensional datasets and produces interpretable clusters through centroid representations.

After TF-IDF transformation and Truncated Singular Value Decomposition, the text features exist in a latent semantic space where Euclidean distance provides a meaningful similarity measure. This makes K-Means an appropriate choice for discovering research-topic structures.

Cluster quality is evaluated using complementary metrics:

  • Silhouette coefficient: measures cluster cohesion and separation.
  • Davies--Bouldin index: evaluates similarity between clusters.

PCA, UMAP, and t-SNE provide complementary visualization perspectives. PCA preserves global variance, UMAP captures local and global neighborhood structures efficiently, and t-SNE highlights local cluster organization.

Supervised Learning: Ridge and Logistic Regression

Two linear baseline models are implemented:

  • Ridge Regression: predicts log-transformed citation counts.
  • Logistic Regression: identifies highly cited papers using a binary classification threshold.

Both models use the same leakage-free feature representation described above and are trained exclusively on the C1 training cohort.

The Ridge Regression model uses:

  • Regularization parameter: \(\alpha=1.0\)

The Logistic Regression classifier uses:

  • C=1.0
  • class_weight="balanced"
  • max_iter=2000

Performance is evaluated using regression, ranking, and classification metrics. In addition, cluster assignments from K-Means are incorporated as engineered features through an ablation study to determine whether unsupervised topic information improves supervised prediction.

Reason for Regression Method

Ridge Regression and Logistic Regression provide interpretable baseline models for high-dimensional sparse features.

Ridge Regression reduces overfitting through L2 regularization while maintaining continuous citation prediction capability. Logistic Regression provides probabilistic predictions for identifying highly cited papers and serves as a transparent classification baseline.

These baseline models establish a reference point for evaluating future nonlinear approaches such as tree-based ensembles and graph neural networks.

4. Results & Discussion

K-Means Clustering

The unsupervised learning pipeline investigates whether latent semantic representations of research papers naturally form meaningful groups and whether these groups exhibit different citation characteristics.

After constructing the 100-dimensional LSA representation from TF-IDF features, two K-Means analyses were performed:

  • Text representation only.
  • Combined text and standardized metadata representation.

Cluster quality was evaluated using the Silhouette coefficient over multiple values of \(k\). PCA, UMAP, and t-SNE were applied to visualize the learned feature space.

The comparison demonstrates that metadata features introduce strong structural information. The combined representation produces a clear interior maximum at \(k=3\), indicating three broad research groups.

For the text-only representation, \(k=8\) was selected because it provides a finer partition while maintaining interpretable and sufficiently populated clusters.

The visualization indicates that highly cited papers are not uniformly distributed throughout the feature space. Instead, they appear concentrated within specific semantic regions, suggesting that textual representation captures meaningful information about future scientific impact.

Metadata-Based \(k=3\) Clustering

The \(k=3\) clustering using text and metadata representations shows consistent separation across PCA, UMAP, and t-SNE projections.

The discovered clusters correspond closely with major research categories:

  • cs.CV Computer Vision
  • cs.CL Computational Language
  • cs.LG Machine Learning and related areas

This demonstrates that K-Means can recover meaningful research domains without explicitly using category labels during training.

Text-Only \(k=8\) Topic Archetypes

The text-only clustering produces finer semantic structures. Analysis of high-weight TF-IDF terms reveals recognizable research themes:

  • Object detection and 3D vision.
  • Reinforcement learning.
  • Optimization theory.
  • Applied machine learning.
  • Deep neural architectures.
  • GANs and adversarial learning.
  • Image segmentation.
  • Natural language processing.

These topic labels are assigned only after clustering by examining representative terms. Therefore, the discovered structures remain entirely data-driven.

Topic clusters exhibit substantially different citation behaviors. Vision-related topics, segmentation, GANs, and NLP contain larger fractions of highly cited papers, whereas optimization-oriented research shows lower citation impact.

The NLP cluster demonstrates particularly strong citation skew, where a small number of transformer-era papers account for a large fraction of citations. This observation further supports the use of logarithmic citation transformation.

Summary of K-Means Findings

  • The coarse clustering using text and metadata features (\(k=3\)) closely matches major arXiv research categories. Citation outcomes differ between groups, with Computer Vision showing approximately 15% top-decile papers, Computational Language approximately 11%, and Machine Learning/Other approximately 8%.
  • The finer text-only clustering (\(k=8\)) identifies interpretable topic archetypes. Vision, segmentation, NLP, and GAN-related clusters exhibit higher citation impact, while optimization theory forms the lowest-impact cluster.
  • The NLP cluster exhibits a heavy-tailed citation distribution, with a mean of 47.6 citations but a median of only 6 citations, demonstrating why log-transformed targets are necessary.
  • The relationship between semantic topic structure and citation impact suggests that text representations provide predictive information before citation variables are introduced.

Regression

Supervised regression experiments evaluate whether engineered features can predict future citation impact. Ridge Regression and additional regression models are compared using standard regression metrics.

Results from the regression experiments will be incorporated after completion of the final evaluation stage.

5. Conclusion and Future Work

This project develops a machine learning framework for predicting scientific citation impact using publicly available paper metadata and textual representations.

The initial unsupervised analysis demonstrates that semantic representations capture meaningful research structures and reveal topic-dependent citation patterns.

Future work will extend the supervised models using nonlinear approaches, including ensemble learning methods, hyperparameter optimization, and graph-based models incorporating citation and collaboration networks.

Ethics & Sustainability

Citation counts contain known biases related to venue prestige, field size, language effects, and demographic disparities. Therefore, predicted impact should not be interpreted as a measure of scientific merit.

The model is intended as a descriptive analytical tool for understanding citation dynamics rather than a decision-making system for evaluating researchers or allocating resources.

Because this analysis is observational, feature importance results represent associations rather than causal relationships. Additionally, citation labels are dependent on the selected data source and may contain incomplete coverage.
