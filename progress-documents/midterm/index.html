1. Introduction & Project Goal

The objective of this project is to predict the long-term citation impact of scientific papers using a mix of textual metadata, author metrics, and venue prestige. By leveraging both unsupervised clustering and supervised regression/classification techniques, we aim to identify the primary driving factors behind academic visibility and assist researchers in evaluating manuscript impact prior to publication.

2. Data Collection & Preprocessing

Our dataset is compiled from the OpenAlex API and Semantic Scholar Open Research Corpus, focusing on 50,000 computer science papers published between 2015 and 2020. This window ensures that papers have had sufficient time to accumulate citations.

Feature Engineering & Data Cleaning

  • Target Variable: citation_count (log-transformed as $\log(y + 1)$ to handle the heavy-tailed distribution).
  • Text Features: Paper titles and abstracts were processed using a pre-trained SciBERT model to extract 768-dimensional dense vector embeddings.
  • Metadata Features: Extracted publication year, page count, and the number of references.
  • Graph & Network Features: Calculated the maximum h-index of the co-authors at the time of publication and the Impact Factor (or h5-index) of the publishing venue.

Missing values in author metrics were imputed using the median, and all continuous features were normalized using StandardScaler to prepare them for distance-based algorithms.

3. Unsupervised Analysis

To discover latent structures and groupings within scientific literature without relying on explicit citation labels, we applied unsupervised learning techniques directly to the text embeddings and metadata features.

Dimensionality Reduction via PCA

Due to the high dimensionality of the SciBERT embeddings (768 dimensions), we applied Principal Component Analysis (PCA). We found that the first 50 principal components retained approximately 85% of the total variance, significantly lowering computational overhead for downstream clustering.

K-Means Clustering

Using the elbow method and silhouette scores, we selected an optimal cluster count of $K = 5$.

Insight: The unsupervised clustering successfully mapped papers into distinct sub-disciplines, revealing that contemporary AI domains (NLP and Computer Vision) inherently carry a significantly higher baseline citation velocity than theoretical sectors.

4. Supervised Baseline Models

We framed the predictive task as a regression problem to estimate the log-transformed citation count. We implemented and evaluated three preliminary models:

  1. Linear Regression (Ridge Lasso): Serves as our baseline to evaluate linear relationships.
  2. Random Forest Regressor: Introduced to capture non-linear feature interactions (e.g., how author h-index acts in synergy with venue impact factor).
  3. Support Vector Regression (SVR): Utilized with an RBF kernel on the top 50 PC components of text embeddings combined with metadata.

5. Preliminary Quantitative Results

The models were evaluated using Mean Squared Error (MSE) and $R^2$ scores on a 20% holdout validation set.

Key Findings & Next Steps

  • Feature Importance: Random Forest feature tracking showed that venue_impact_factor and author_max_h_index were the strongest predictive features, heavily outperforming raw text features alone.
  • Overfitting: The Random Forest model shows signs of overfitting given the gap between train and validation metrics. We intend to address this via hyperparameter tuning (limiting max_depth) and dropout regularization in future iterations.
  • Future Work: For the final phase, we plan to transition from simple regression models to LightGBM / XGBoost and experiment with training a Graph Neural Network (GNN) over the co-authorship network.
